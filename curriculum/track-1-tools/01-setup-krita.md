# T1-01 — Setup & Orientation

**Tool:** Krita
**Goal:** Get Krita installed and configured for animation, and make your first throwaway doodle so the software stops being intimidating.

## Steps

1. **Install Krita** (if not already): [krita.org/download](https://krita.org/en/download/). Any recent version is fine.
2. **Get the drawing tablet working** — your XP-Pen should be recognized and producing pressure-sensitive strokes in a test scribble. Deeper pen comfort (grip, buttons, shortcuts) is Track 4's whole job, starting right after this lesson — worth not skipping even though it delays "real" drawing slightly.
3. **Enable the Animation workspace**: `Window → Workspace → Animation` (or build your own layout with the Timeline and Onion Skin dockers visible: `Settings → Dockers → Timeline` / `Onion Skin`).
4. **Tour the interface** — find and click on:
   - The **Timeline** docker (bottom) — this is your frame-by-frame strip.
   - The **Onion Skins** docker — toggle it on, it should tint previous/next frames. Onion skinning is also per-layer: make sure the little light-bulb icon is lit on the layer you're drawing on, in the Layers docker, or you won't see anything even with the docker enabled.
   - The **Layers** docker.
   - Brush presets on the right toolbar — find a simple round pencil-like brush (e.g. "Pencil-2") and a basic ink brush (e.g. "Ink_gpen").
5. **New file for a test animation**: `File → New`, any small canvas (e.g. 1280x720), and set the frame rate to 12 fps in the **Animation Timeline docker's** frame-rate field (there's no separate "Image → Animation" dialog — it lives in the Timeline docker itself, or in the New Document dialog's animation section). 12fps is the traditional hand-drawn animation standard, don't use 24/30 yet.
6. **Make 3-4 throwaway frames** of literally anything moving — a scribble that grows, a dot that bounces once. Right-click the timeline to add frames. Just confirm you understand:
   - Adding a new frame
   - Onion skinning showing the previous frame faintly
   - Playing back with the playback controls (space bar or the play button)

Don't aim for quality here. The only goal is: "I know where the buttons are."
